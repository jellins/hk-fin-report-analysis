# 港股版回归测试方案（Regression Plan）

> 港股版 `hk-fin-report-analysis` 正式发布前必须完成以下三组真实数据回归测试。每个测试须产出完整诊断报告并核对「预期命中项」——方法论的价值在于可复现的裁决，而非叙事。

## T1 — 排雷验证：中国恒大（3333.HK）

**目的**：验证框架能在暴雷前/暴雷中识别高危标的（港股史上最大地产暴雷案）。

- **数据纪律（后视镜偏差禁令）**：一律使用暴雷前**原始披露**数据（含后被证明造假的 FY2019–FY2020 原披露报表）执行诊断，禁止使用事后回溯调整数据——方法论的价值在于用当时可得信息排雷；可另跑修正后数据作稳健性对照，但以原始数据下的裁决为准
- **数据区间**：FY2017–FY2021（暴雷前五年）三表 + 供股/配售/派息记录 + 核数师变更记录 + 永续债及合联营附注
- **预期命中**：
  - H1-01 债务到期墙预警（到期集中 + 境外美元债占比高 + 本币贬值错配）
  - H1-02 永续债还原检查命中（还原后有息负债率与利息保障显著恶化）
  - H2-03 合联营暴露预警/红灯（应占合联营业绩占比与担保网络）
  - S1-02 有息负债率超线（地产豁免口径下仍高危）
  - S5-06 表外或有事项红灯（合营/联营表外负债、担保网络）
  - S4-07 股东回报检验预警（累计分红超累计自由现金流 = 借钱分红；累计分红 vs 累计融资、大股东分红套现）
  - S4-06 现金流肖像：蛮牛型（+−+）主导或边际恶化
  - G0-06：2023 年后清盘呈请 + 长期停牌 → 直接排除（现行状态验证）
- **预期评级**：高风险回避 或 直接排除
- **否决标准**：若评级为「优质候选」或「可关注」且无红灯，说明排雷层失效，须回炉字典

## T2 — 识好验证：腾讯控股（0700.HK）

**目的**：验证框架不误伤优质公司（港股最优质标的之一），同时验证 RMB 记账本位币与 Non-IFRS 处理。

- **数据区间**：最近 5 个财年三表 + Non-IFRS 披露 + 股本变动记录
- **预期命中**：
  - H0-01 老千股闸口：五项全部不命中（无供股/合股史、无频繁更名）
  - S2-14 合约负债 / S4-02 利润含金量 / S4-07 股东回报 正向
  - S4-06 现金流肖像：奶牛型（+−−）或老母鸡型主导
  - H3-01 Non-IFRS 差异率：有披露，差异率在阈值内（SBC 与投资损益为主项），方向无反转
  - **S3-04 两阶段裁决观察点**：处置收益大年（投资/出售收益占除税前溢利比高）应判「主业成色仍优」预警而非红灯——若直接红灯，复核两阶段规则执行
  - **H2-04 每股裂口观察点**：2022 年起大额回购注销，EPS 增速 ≥ 归母净利增速（裂口 ≤0，应记正向证据）
  - 币种纪律验证：RMB 记账本位币在回执与报告中正确注明
- **预期评级**：优质候选（允许因单一预警降为可关注，但红灯必须为 0）
- **否决标准**：若出现否决级红灯，须逐项复核是腾讯真实问题还是框架误伤，并记录裁决依据

## T3 — A+H 对照实验：比亚迪（1211.HK / 002594.SZ）

**目的**：验证方法论跨市场一致性——同一实体 CAS 口径（A 股版 skill）与 HKFRS 口径（港股版 skill）双跑。

- **执行方式**：
  1. 港股侧：本 skill 内置源（scripts/，HKFRS 口径，HKD/RMB 注意比亚迪港股财报记账本位币）
  2. A 股侧：a-share-fin-report-analysis 内置源（CAS 口径）
  3. 一致性核对：两侧归母净利润 / 净资产 / 经营现金流差异应 <5%，超限必须解释（准则差异/口径调整）
  4. 结论核对：两侧七层结论应**同向**；若一侧红灯一侧放行，复盘是准则差异还是框架缺陷
- **预期结果**：双口径数值基本一致，评级同向
- **否决标准**：数值差异 >5% 且无准则解释，或评级方向相反且无合理归因 → 回炉检查映射表
- **补充对照**：招商银行（3968.HK / 600036.SH）仅作双口径数值一致性验证（银行走金融专用框架，G0-05 终止是正确行为——两侧都应在闸口终止，本身即一致性证据）
