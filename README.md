# hk-fin-report-analysis

> 让任何 AI Agent 都成为纪律严明的港股财报侦探——港股财报诊断与排雷 Skill（HKFRS 版）

一套可被主流 AI Agent（Claude Code、WorkBuddy、Cursor 等）直接加载使用的港股财报诊断能力包。与 [a-share-fin-report-analysis](#同族-skill)、[us-fin-report-analysis](#同族-skill) 同族：**方法论内核完全一致**，本仓库承载 HKFRS 准则映射与港股特有检查项。

**设计立场：Agent 不自由发挥财务分析。** 全部 58 项指标的公式、口径、参照线、裁决规则写死在指标字典中；每一个进入计算的数字必须携带可溯源回执；取不到的数据标 MISSING、禁止估算编造。Agent 的角色被严格限定为「执行固定流程 + 按固定规则裁决」。

## 为什么需要专门的港股版

同一套财报诊断方法论迁移到港股时，三表联动、现金验证、现金流肖像、杜邦拆解等内核可以直接复用（HKFRS 与 CAS 同宗 IFRS，准则是三个市场版中差异最小的），但港股的**市场生态风险结构**与 A 股/美股截然不同，硬套会产生盲区：

- **港股的雷不在报表里，在报表外的股本游戏里**：老千股通过「供股摊薄 → 向下炒 → 合股 → 再供股」循环收割小股东，财务报表完全可能看起来正常——必须先过老千股结构闸口，再看财务数字
- **准则差异点**：HKFRS 允许投资物业公允价值模式（重估损益直进利润表且非现金，地产公司利润注水主通道）、允许 PP&E 重估（重估储备虚增净资产压低 ROE）、允许开发支出资本化；**永续债计入权益**同时美化负债率与利润（票息走权益分配、不进利润表）
- **市场特有机制**：WVR 同股不同权（-W）、18A 未盈利生物科技（-B）、第二上市（-S）、RTO 反向收购借壳、做空报告高发（浑水/香橼经典战场）、2024 年库存股新规（回购可不注销）
- **基础设施差异**：记账本位币多样（HKD/RMB/USD）、财年截止日多样（3/31、6/30、12/31）、中期报告普遍未经审计

本 Skill 为这些问题提供固化的检查项与裁决规则（H 系列指标），而不是依赖 Agent 的自由发挥。

## 思想来源

方法论框架蒸馏自唐朝《手把手教你读财报（新准则升级版，2021）》，其核心立场市场无关、全球通用：

- **财报是排雷工具，不是选股神器**
- **利润是算出来的估计值，现金才是真金白银**——一切利润必须经过现金流验证
- **顺着资金流向读财报**：钱从哪来 → 钱花到哪 → 钱赚得真不真
- **任何指标只有在自身 5 年趋势与同行对比中才有意义**

本 Skill 为框架与思想的蒸馏重构并按 HKFRS 适配，**不含原书原文复述**。

## 能力细项

### 排雷：识别并淘汰坏公司

七层漏斗，从结构风险到报表细节逐层收紧，**58 项指标全部机械裁决**（否决级 12 项红灯 = 直接排除；风险级 18 项；其余为预警/观察项）：

| 层 | 检查重点 | 代表性裁决规则 |
|---|---|---|
| 第 0 层 前置闸口 | 行业适用性、清盘/停牌/除牌状态、审计意见、上市年限、**老千股结构闸口** | H0-01 五项量化检查（供股/合股频率、连续 12 个月月均股价 <HK$1、频繁更名换主业、股权集中度、折价配售）命中 ≥2 项 → 不看报表直接排除；审计报告含持续经营（going concern）段落 → 风险级红灯 |
| 第 1 层 安全性 | 现金覆盖有息负债、存贷双高、**永续债还原**、债务到期墙（含外币债维度） | 内房/基建/综合企业必须先把权益内永续债还原进负债、票息还原进利息，再算负债率与利息保障；利息保障分母强制含资本化利息；存贷双高 + 利息收入异常 → 否决级红灯（现金真实性存疑） |
| 第 2 层 资产质量 | 应收/存货/商誉造假组合、**合联营表外暴露**、**每股增长裂口**、股本稀释 | 应收增速持续 > 营收增速 → 否决级；存货周转降 + 毛利率升 → 否决级；应占合联营业绩占比 >30% 或资产暴露 >50%〔经验值〕→ 红灯（内房表外藏债主通道）；净利增速 − EPS 增速裂口 >3pp/年 → 股本游戏吞噬股东回报 |
| 第 3 层 盈利质量 | 毛利率、费用率、研发资本化、主业成色、**明股实债裂口**、Non-IFRS 美化 | 无支撑显著高于同行的毛利率 → 否决级；NCI 损益占比 ≫ NCI 权益占比 → 红灯（明股实债）；Non-IFRS 差异率持续 >30% 或方向反转 → 红灯 |
| 第 4 层 现金验证 | 营收含金量（间接法推导）、利润含金量、现金流肖像、股东回报 | 利润含金量长期累计 <0.5 → 否决级；**累计分红 > 累计自由现金流 → 借钱分红预警**（恒大画像核心特征）；融资多回报少 → 提款机特征，与老千股闸口互证 |
| 第 5 层 管理层与治理 | 大股东质押/减持、核数师辞任、关连交易、表外或有、做空报告 | 核数师「辞任」（非轮换）→ 红灯；**财报否决级异常独立成立 + 做空指控互证 → 直接排除**（财报无异常时做空仅触发强制下钻，不替做空机构站台） |

### 识好：识别好生意、好公司

排雷只是及格线，「识好」有独立的正向指标体系：

| 维度 | 指标 | 好生意的财务特征 |
|---|---|---|
| 资本回报 | ROE + ROIC 双核心（H6-01 失真检查后） | ROIC（剔杠杆、剔重估损益、含永续债还原、净现金剔超额现金）连续多年 ≥12%〔经验值〕或同行前 1/3 |
| 定价权 | S3-09 毛利率稳定性 | 5 年毛利率变异系数显著低于同行 + 成本上行期毛利率保持 = 真护城河；大起大落 = 周期股 |
| 资本配置 | S6-06 增量资本回报 | ΔNOPAT ÷ Δ投入资本持续 ≥12%〔经验值〕= 留存利润仍在高效再投资；持续 <8% = 增长靠堆资本 |
| 每股真实增长 | H2-04 每股裂口 | 回购注销驱动 EPS 增速 > 净利增速（裂口为负）= 股东回报为真；供股配售驱动裂口为正 = 总量增长的假象 |
| 产业链地位 | S2-14 合约负债强度 / S2-15 上游占款 | 先款后货 + 无偿占用上游（附资金链断裂式占款的交叉验证，防止反向误读） |
| 现金造血 | S4-06 现金流肖像（多期主导型） | 奶牛型（+−−）/ 老母鸡型（++−）主导，事件扰动不从序列剔除 |
| 股东回报 | S4-07 分红 + 回购注销检验 | 经营现金流为正 + 持续高分红或大额回购注销 = 利润真实性的最强佐证 |

最终输出四档质地评级：**优质候选 / 可关注 / 高风险回避 / 直接排除**，评级由字典「评级聚合规则」机械裁决（四档门槛 → 降档规则 → 上限裁剪 → 状态标注），含三硬条件（ROE/ROIC 达标 + 现金流肖像健康 + 利润含金量 ≥1）与加分项计数，Agent 无自由裁量空间。**输出企业质地判断，不含估值与买卖建议。**

### 港股特有检查项（相对 A 股版的增量）

| 检查项 | 解决的问题 |
|---|---|
| H0-01 老千股结构闸口 | 供股/合股频率、长期低价、频繁更名、股权集中度、折价配售五项复合检查（全部量化阈值），先于一切财务指标 |
| H0-02 上市机制标记 | WVR / 18A / 第二上市 / GEM 识别并改变裁决口径（18A 改现金跑道裁决，不与肖像规则死锁） |
| H1-02 永续债还原检查 | 永续债入权益同时美化负债率与利润（票息不进利润表），内房/基建必须还原后裁决 |
| H1-01 债务到期墙（含外币维度） | 到期集中 + 高浮动占比 + 美元债/本币错配——内房暴雷标准组合 |
| H2-01 股本稀释（港股口径） | 供股/配售是港股摊薄主机制，年增 >10% 或 5 年 ≥2 次供股即预警（含库存股口径核对） |
| H2-03 / H2-04 合联营暴露与每股裂口 | 内房表外藏债量化闸口；净利增速与 EPS 增速裂口识别股本游戏吞噬股东回报 |
| S2-12 投资物业计量（强化） | HKFRS 公允价值模式下重估损益直进利润表，盈亏双向剔除后重估盈利 |
| H6-01 ROE 失真双向检查 | 回购压净资产（美股向）+ 重估储备/永续债虚增净资产（港股特有向）；ROE 与 ROIC 双核心并列 |
| H3-01 Non-IFRS 差异率 | 腾讯等公司 Non-IFRS 调整的美化识别 |
| H5-02 做空报告跟踪 | 财报否决级异常独立成立为前提、做空为增强证据 → 直接排除；不对赌、不站台 |
| S3-09 / S6-06 识好指标 | 毛利率稳定性（定价权代理）+ 增量资本回报（资本配置能力），补齐「识好」维度 |
| S4-01' 营收含金量推导式 | 港股现金流量表普遍间接法，用 收益 − Δ应收 + Δ合约负债 推导收现（禁止从 CFO 反推，高毛利公司会系统性失真） |
| A+H 对照实验机制 | 同一实体 CAS/HKFRS 双口径一致性验证 |
| 行业豁免表 | 互联网轻存货 / 地产 / 公用事业 / 零售 / **REIT（FFO 口径）** / 未盈利企业（现金跑道）六类行业口径调整 |

## 数据严谨性设计：固定框架 + 真实数据 + 零编造

本 Skill 防幻觉的机制是**执行顺序的硬性倒置**——先锁定分析框架与指标，再取数填数；而不是让 LLM 先形成观点再找数据佐证。

```
方法论层（不可变）   七层诊断框架 + 指标字典（58 项指标，公式/口径/裁决规则写死）
      │ 反推
契约层（固定格式）   数据需求清单（A–E 五组字段，编号冻结；▲核心字段 18 项一票否决）
      │ 路由
数据源层（可插拔）   内置源（scripts/ 自研脚本：东财三表主源 + 双交叉核对 + 治理 + 披露易）
                    自定义源（Bloomberg/Wind/Excel/内部平台 → C1–C5 准入校验）
      │ 产出
回执层（强制）       每个数值必须携带 {值, 财年, 币种, 来源, 原始字段, 获取时间}
```

### 港股财报数据如何获取（内置源，开箱即用）

内置源为本仓库 `scripts/` 自研脚本（仅依赖 requests，CLI 调用，stdout 输出 envelope 回执），不依赖任何外部数据 skill：

| 优先级 | 数据源 | 负责范围 |
|---|---|---|
| 首选（三表主源） | `scripts/fetch_hk.py` → 东财港股 F10 三表接口（RPT_HKF10_FN_BALANCE / RPT_HKF10_FN_INCOME / RPT_HKSK_FN_CASHFLOW，年报过滤） | A/B/C 组主体字段；逐行透传准则与币种标注 |
| 交叉核对①（同司双源） | `scripts/fetch_hk.py` → 东财 GMAININDICATOR 港股指标（75 字段） | B01/B17/B26 绝对额交叉（容差 0.5%，超差进 conflicts 不仲裁任选）+ 毛利派生核对 + B22 加权稀释股数推导 |
| 交叉核对②（币种锚） | `scripts/fetch_hk.py` → Yahoo Finance 年报营收锚 | 验证东财币种标注（记账本位币与交易币种混淆的实证防线）；锚不可用降级为 warning，不阻塞主数据 |
| 治理数据 | `scripts/fetch_hk_governance.py` → 东财 CompanyProfile + GMAININDICATOR + 现金流量表推导 | D09 上市日期 / D12 核数师 / D20 板块 / D13 每股股利与派息比率 / D14 股权融资；三通道独立成败互不阻塞 |
| 披露原文（S 级） | `scripts/fetch_hk_announce.py` → 联交所披露易（HKEXnews） | 公告检索（年报/业绩/供股/配售/合股/核数师/派息/回购等 10 预设）+ PDF 下载（%PDF 头校验）；红灯下钻与 D 组治理字段的法定来源 |
| A+H 对照 | `a-share-fin-report-analysis` skill 内置源 | A+H 双上市公司的 A 股侧 CAS 口径三表，供跨市场一致性验证 |

脚本内置质量防线（非人工步骤）：行级 sanity 三规则（净利>营收×1.05 / 营收≤0 / 权益<0 → 脏行整期拒绝）；现金流科目符号 abs 规范化；结构性零值字段（A37 永续/B24 合联营/A38 库存股/C08 回购，无科目填 0 不绕过结构性检查）；同域限流 + 429/5xx 指数退避 + 15s 超时；失败语义分级退出码（0 成功 / 3 参数 / 4 接口故障 / 5 风控）。冒烟测试清单见 `scripts/selftest.md`。

### 交叉验证体系（四道防线）

1. **同司双源交叉核对（脚本内置）**：三表主源 vs GMAININDICATOR 指标表绝对额交叉（容差 0.5%），超差写入 conflicts 如实呈现、不仲裁任选；Yahoo 年报营收锚验证币种标注（实测腾讯：东财 CNY 标注与 Yahoo financialCurrency 一致，年报 totalRevenue 7517.66 亿两源完全吻合）
2. **结构化数据 vs 披露原文**：红灯指标必须下钻年报附注/公告原文（披露易）再裁决，结构化数据只负责初筛；字段断档时以原文人工摘录补齐并注明「年报原文摘录」
3. **A+H 双口径对账**：同一实体 CAS 与 HKFRS 两套披露，归母净利/净资产/经营现金流差异 >5% 必须解释来源（准则差异/口径调整）；准则混排禁止（东财逐行 `ACCOUNT_STANDARD` 标记，跨年度准则切换必须重组序列）；科目映射跨年断档以 A 股侧口径为准重组（实测案例：CATL 应收科目断档曾致增速差假性 +88pp 尖峰）
4. **自定义源准入校验（C1–C5）**：能力覆盖声明 → 口径合规（合并报表/归母/币种/准则）→ 字段完整性（▲核心字段 18 项不可缺）→ 可溯源性 → 样本抽验（随机抽收益/经营现金流与内置源或原文交叉核对，偏差须在舍入误差内）；不通过则拒绝采用

### 防 LLM 编造的硬性纪律

- **唯一指标来源**：指标字典是唯一准绳，禁止自创指标、修改公式、脱离口径计算
- **无回执不计算**：任何无来源回执的数值禁止进入计算与结论
- **MISSING 分层处置**：取不到标 MISSING，禁止估算填充；公司无某科目（无永续债/无合联营）回执填 0 并注明「无此科目」，不得以 MISSING 绕过结构性检查
- **禁止单年定性**：一切裁决落到连续 ≥5 个财年趋势 + 同行业 2–3 家对比
- **〔经验值〕阈值声明**：源自 A 股经验的阈值仅为初筛代理，港股一律以同行对比为最终裁决

### 使用

自然语言描述即可触发：

- 「帮我分析一下腾讯的财务质地」
- 「这只港股是不是老千股」
- 「用我导出的这份数据诊断一下美团」（触发自定义数据源 C1–C5 准入校验）
- 「对比比亚迪 A 股和港股两侧财报口径是否一致」（A+H 对照实验）

### 数据依赖

内置源开箱即用：仅需 Python 3.9+ 与 `requests`（`pip install requests`），**不依赖任何外部数据 skill 或付费终端**；三表、交叉核对、治理字段、披露易公告全部由 `scripts/` 自研脚本直连公开接口获取。

两个可选扩展：

- **A+H 对照实验**：需同族 [a-share-fin-report-analysis](https://github.com/simonlin1212/a-share-fin-report-analysis)（其内置源提供 A 股侧 CAS 口径数据）
- **自定义数据源**：Bloomberg/Wind/Excel/内部平台等，经 C1–C5 准入校验后优先于内置源（结构契约见 `templates/`）

## 回归测试

发布前必须通过三组真实数据回归（`tests/regression-plan.md`）：

- **T1 排雷**：中国恒大（3333.HK，FY2017–2021）——**后视镜偏差禁令**：只用暴雷前原始披露数据，预期命中永续债还原、合联营暴露、借钱分红、到期墙等多重红灯
- **T2 识好**：腾讯控股（0700.HK）——验证不误伤优质公司，含 RMB 本位币、Non-IFRS、回购注销、S3-04 两阶段裁决观察点
- **T3 对照**：比亚迪（1211.HK / 002594.SZ）——A+H 双口径一致性（差异 <5%）与结论同向验证
