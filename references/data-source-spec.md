# 数据源规范（Data Source Specification）— 港股版

> 定义港股财报诊断的数据获取架构：默认源路由、自定义数据源准入、数据回执与降级规则。
> 核心原则：**方法论不可替换，数据源可以替换**；任何数据源都只是「数据需求清单」的填空者。

## 1. 架构分层

```
方法论层（不可变）     七层诊断框架 + 指标字典（indicator-dictionary.md，HKFRS 版）
        │ 反推
契约层（固定格式）     数据需求清单（A–E 五组字段）
        │ 路由
数据源层（可插拔）     内置源（scripts/ 自研脚本，开箱即用）/ 自定义源（声明 → 校验 → 分级）
        │ 产出
回执层（强制）         每个数值必须携带 {值, 财年, 币种, 来源, 原始字段, 获取时间}
```

## 2. 默认数据源路由（用户未声明自定义源时）

内置源为本 skill 自研脚本（`scripts/`，仅依赖 requests，CLI 调用，JSON 回执输出），开箱即用：

| 优先级 | 数据源 | 负责范围 |
|---|---|---|
| 首选（三表主源） | `scripts/fetch_hk.py` → 东财港股 F10 三表接口（RPT_HKF10_FN_BALANCE / RPT_HKF10_FN_INCOME / RPT_HKSK_FN_CASHFLOW，年报过滤 REPORT_TYPE=="年报"） | 覆盖 A/B/C 组主体字段；逐行透传 ACCOUNT_STANDARD/CURRENCY |
| 交叉核对①（同司双源） | `scripts/fetch_hk.py` → 东财 GMAININDICATOR 港股指标（75 字段） | B01/B17/B26/B27 绝对额交叉（容差 0.5%，超差进 conflicts 不仲裁任选）+ 毛利派生核对（B01−B02 vs GROSS_PROFIT）+ ROE/ROIC 等派生比率 INFO 级参考 + B22 加权稀释股数推导 |
| 交叉核对②（币种锚） | `scripts/fetch_hk.py` → Yahoo Finance quoteSummary（cookie+crumb 公开鉴权） | financialData.financialCurrency + 年报 totalRevenue 锚，验证东财 CURRENCY 标注（Fix-10：比值≈1 → 数值实为财报币种并纠正；锚缺失 → currency_unverified 不静默）；校验源故障不阻塞主数据 |
| 治理数据 | `scripts/fetch_hk_governance.py` → 东财 CompanyProfile + GMAININDICATOR + 现金流量表推导 | D09 上市日期 / D20 板块 / D12 现任核数师 / D13 每股股利与派息比率 / D14 股权融资（发行股份科目推导）；三通道独立成败互不阻塞 |
| 披露原文（S 级） | `scripts/fetch_hk_announce.py` → 联交所披露易（HKEXnews） | 公告清单检索（预设矩阵：年报/年度业绩/供股/配售/合股/核数师/更名/派息/回购/关连交易）+ PDF 下载（%PDF 头校验）；D 组治理字段的法定来源，字段提取由 Agent 阅读 PDF 完成 |
| A+H 对照 | `a-share-fin-report-analysis` skill（同族 A 股版）内置源 | A+H 双上市公司的 A 股侧三表与指标（CAS 口径），供跨市场一致性验证 |

内置源质量防线（脚本内置，非人工步骤）：
- **行级 sanity 三规则**：净利>营收×1.05 / 营收≤0 / 权益<0 → 整期拒绝并入 meta.rejected_periods 审计（脏行不进入 items）
- **符号规范化**：CapEx/股息/利息/回购等现金流科目一律 abs（符号口径混杂实证教训）
- **结构性零值**：A37 永久资本证券 / B24 应占合联营 / A38 库存股 / C08 回购 无此科目填 0（不构成 MISSING，禁止绕过结构性检查）
- **失败语义分级**：exit 0=成功（允许 MISSING/CONFLICT）/ 3=参数错误 / 4=接口故障 / 5=风控；限流（同域 ≥1s+随机抖动）+ 429/5xx 指数退避重试 + 15s 超时

路由与合规规则：
1. 东财港股接口为结构化主力源；字段缺失或断档时以年报原文（披露易 PDF，经 fetch_hk_announce.py 落地）人工摘录补齐，回执注明「年报原文摘录（页码）」
2. **币种纪律**：港股公司记账本位币多样（HKD/RMB/USD），每个回执必须注明币种；内置源经 Yahoo 锚交叉验证后于 meta.currency 输出裁决值（items 内保留东财原始标注作证据）；跨公司对比统一折算为一个币种（建议港币或人民币）并在报告注明折算汇率来源与日期
3. **财年纪律**：港股财年截止日多样（3/31、6/30、12/31），对照组对比时在报告注明各公司财年截止月份，禁止把不同截止月份的数据当作完全同期处理而不加说明
4. 供股/合股/配售记录（D14）是 H0-01 老千股闸口与 H2-01 的命脉字段：现金流推导（fetch_hk_governance.py）给金额序列，折价率与频率以披露易公告（fetch_hk_announce.py --preset rights/placing/consolidation）全量回溯，**不得省略**
5. A+H 双上市公司：必须同时取 A 股侧（a-share-fin-report-analysis 内置源，CAS 口径）与港股侧（本 skill 内置源，HKFRS 口径），同一实体两套口径的归母净利/净资产/CFO 做一致性核对，差异 >5% 须在报告中解释来源（准则差异/口径调整）
6. 任何字段无法获取 → 回执标注 `MISSING`，禁止估算填充

### 2.1 CAS/IFRS 披露公司取数纪律（T3 回归新增，强制）

H 股/红筹公司可按 CAS（大陆会计准则）或 IFRS 披露，东财港股接口逐行带 `ACCOUNT_STANDARD` 标记。执行时：

1. **准则混排禁止**：逐行检查 `ACCOUNT_STANDARD`；同一序列跨年度准则切换（典型：招股书 track record 为 IFRS、年报为 CAS，如宁德时代 3750.HK 的 FY2022/23=IFRS、FY2024/25=CAS）→ 必须按同准则重组序列后再做趋势分析，禁止混排直接算增速/趋势；回执逐年注明准则口径
2. **科目映射跨年一致性校验**：东财港股科目映射可能跨年度断档（实测 CATL：应收帐款科目 FY2022/23 = 应收票据及应收账款口径，FY2024/25 = 应收账款+应收款项融资合并口径，断档致 S2-02 假性 +88pp 尖峰）。A+H 双上市公司必须逐科目与 A 股侧（a-share-fin-report-analysis 内置源）交叉核对，发现断档 → 以 A 股侧口径为准重组并标注混合来源
3. **上市不足 5 年的港股标的**：三表不足 5 财年时，用招股书 track record 或同实体 A 股年报（CAS 同准则）补齐至 5 年，回执注明补齐来源；G0-03 上市年限降权照常执行
4. **「应付票据」消歧**：CAS 披露公司的应付票据为贸易票据（非有息负债），并入 S2-15 上游占款分子而非有息负债——与指标字典 S1-01 脚注一致

## 3. 自定义数据源准入（对话声明 + 即时校验）

### 3.1 触发方式

用户声明使用自有数据源（Excel/CSV、Bloomberg/Wind/同花顺 iFinD 终端、内部数据平台、自建 API 等）时，自定义源**优先于默认源**，但须先通过准入校验。

### 3.2 准入校验清单

| # | 校验项 | 通过标准 |
|---|---|---|
| C1 | 能力覆盖声明 | 明确覆盖数据需求清单 A–E 中哪些组、缺哪些组；缺失组是否同意回落默认源 |
| C2 | 口径合规 | 确认为合并报表口径；利润字段为归母口径（本公司拥有人应占溢利）；能区分财年；**注明记账本位币与单位**（千/百万港元等）；注明准则口径（HKFRS/IFRS/CAS） |
| C3 | 字段完整性 | A+B+C 组必需字段 100% 覆盖为完全通过；核心字段（3.4）缺失 → 不得通过 |
| C4 | 可溯源性 | 每个数值能标注来源与财年；无法溯源的数值拒绝采用 |
| C5 | 样本抽验 | 随机抽 1–2 个科目（建议收益 revenue、经营现金流 CFO）与东财港股接口或年报原文交叉核对，偏差须在舍入误差范围内 |

### 3.3 校验结果分级

| 等级 | 条件 | 处置 |
|---|---|---|
| ✅ 完全通过 | C1–C5 全部通过 | 全部采用自定义源 |
| ⚠️ 部分通过 | 非核心字段缺失且用户同意回落 | 缺失字段回落默认源，回执注明混合来源 |
| ❌ 不通过 | 核心字段缺失/口径不合规/不可溯源/抽验异常 | 拒绝采用，说明原因与补齐路径，询问改用默认源或补充数据 |

### 3.4 核心字段（▲ 不可缺失清单）

收益｜销售成本｜归母净利润｜年度溢利｜非控股权益损益｜经营现金流净额｜总资产｜总负债｜归母权益｜现金及现金等价物｜短期 + 长期借贷｜贸易应收款项｜存货｜商誉｜资本开支｜永久资本证券（A37）｜应占合营及联营企业业绩（B24）

> 注：A37/B24 为结构性检查字段——公司无永续债或无合联营时回执填 0 并注明「无此科目」，不构成缺失；禁止以「无数据」名义跳过 H1-02 永续债还原 / H2-03 合联营暴露检查。同类结构性字段：A38 库存股、C08 回购股份付款（同样适用填 0 规则）。

## 4. 数据回执机制（防幻觉强制约束）

内置源脚本输出 envelope 回执（items/conflicts/errors/meta），单条数值结构：

```
{
  "field_id": "C02",
  "value": 303052000000,
  "period": "2025-12-31",
  "source": "em_dc_RPT_HKSK_FN_CASHFLOW",
  "raw_field": "经营业务现金净额",
  "retrieved_at": "2026-10-19T19:00:00+08:00",
  "unit": "CNY",
  "currency": "CNY",
  "status": "OK",          // OK | MISSING | CONFLICT
  "note": ""
}
```

纪律：无回执数值禁止进入计算与结论；取不到标 `MISSING`，禁止估算编造；公司无该科目（无永续债/无合联营/无库存股）时回执填 0 并注明「无此科目」，不构成 MISSING；双源超差字段标 `CONFLICT` 并列双值（conflicts 数组），禁止仲裁任选；报告关键指标必须可回溯来源。

## 5. 合规声明

- 本 Skill 只提供方法论、指标定义与数据源调用指引，**不分发、不转售任何市场数据**
- 联交所披露易公告为公共披露；东财接口数据为公开聚合数据；商业终端数据（Bloomberg/Wind 等）由使用者按授权协议自行使用
- 本 Skill 输出为企业质地判断，不构成投资建议
