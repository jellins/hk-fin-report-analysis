# 港股财报诊断清单（七层框架 · HKFRS 版 v1）

> 本清单提供七层框架的判断逻辑与经验说明；指标的**执行语义（公式/口径/阈值/裁决/红灯分级）以 `indicator-dictionary.md` 为唯一准绳**，评级聚合以字典「评级聚合规则」章节为唯一依据。
> 方法论内核与 A 股版（a-share-fin-report-analysis）、美股版（us-fin-report-analysis）同构，本文件只描述港股市场的适配判断逻辑。

**总则（凌驾于一切单条规则之上）**
1. 任何指标的裁决必须落在两个维度上：**自身连续 ≥5 个财年趋势 + 同行业 2–3 家对比**。单年快照只用于初筛，不用于定性。
2. 全部指标基于**合并报表**与**归母净利润（本公司拥有人应占溢利）**口径。
3. 任一指标亮红灯 → **下钻披露原文**（年报附注、业绩公告、供股/配售公告、权益披露、做空报告原文）→ 再裁决。
4. 港股特有意识：**港股的雷不在报表里，在报表外的股本游戏里**——先看 H0-01 老千股闸口，再看财务数字。一个反复供股合股的公司，报表再漂亮也不碰。
5. 币种与财年：港股公司记账本位币（HKD/RMB/USD）与财年截止日（3/31、6/30、12/31）多样，跨公司对比前必须对齐并注明。

## 第 0 层 前置闸口（任一不过，终止分析）

> 执行顺序：行业适用性（G0-05）与风险警示（G0-06）优先；全部港股标的另过 H0-01 老千股闸口。

- **G0-05 行业适用性**：银行/保险/券商/多元金融 → 终止诊断（金融企业指标体系完全不同：资本充足率、不良率、拨备覆盖率，本框架强行套用会系统性误判）
- **G0-06 风险警示**：清盘呈请未解除、长期停牌（主板连续 ≥18 个月 / GEM 连续 ≥12 个月触发除牌程序）、已进入除牌程序 → 直接排除
- **G0-01 审计意见**：近 5 财年全部无保留意见；带强调事项段的无保留意见 → 通过但记预警；**含持续经营（going concern）重大不确定性段落 → 风险级红灯并强制下钻**（暴雷前兆，严重性区别于一般强调事项）；核数师变更须读辞任函——港股核数师「辞任」往往伴随审计分歧，比到期「轮换」危险得多
- **G0-03 上市年限**：借壳（港股称反向收购 RTO）自反收购完成日起重新起算；壳股历史数据不可信
- **H0-01 老千股结构闸口（港股版的灵魂检查）**：供股/合股频率、长期低价、频繁更名换主业、股权高度集中、反复折价配售五项复合检查，命中 ≥2 项直接排除。老千股的本质是**通过股本游戏收割小股东**——供股摊薄 → 向下炒 → 合股 → 再供股的循环，财务指标完全可能看起来正常，必须先于一切财务分析执行
- **H0-02 上市机制标记**：WVR（-W）/ 18A（-B）/ 第二上市（-S）/ GEM 不否决但改口径：18A 未盈利 → 盈利层失效、评级上限「可关注」；WVR → 治理层从严（同股不同权下小股东保护天然弱化）

## 第 1 层 安全性（能不能活）

- 现金覆盖线与有息负债率沿用主口径；内房股等高杠杆行业叠加 H1-01 债务到期墙必查——港股地产的雷多爆在「到期墙 + 境外美元债 + 本币贬值」组合上（H1-01 已含外币债务占比维度）
- **永续债还原先行（H1-02）**：内房/基建/综合企业先查权益内永久资本证券，还原负债本金与票息后再算有息负债率、利息保障与 ROE——永续债是港股美化杠杆与利润的经典通道（票息走权益分配不进利润表），未还原的负债率与利息保障倍数一律不可信
- **利息保障倍数分母必须含资本化利息**（C11）：内房把利息大量资本化进发展中物业，利润表融资成本只是冰山一角
- 存贷双高在老千股语境下从严：账上巨额现金 + 持续供股融资是最典型的矛盾信号（现金若为真，何须反复伸手向小股东要钱）
- 币种错配结构性注明：人民币收入 + 美元债是内房股的标准风险结构

## 第 2 层 资产质量（家底真不真）

- 应收/存货/商誉的造假逻辑与 A 股完全一致——悖论组合（周转降 + 毛利率升）同样是铁红灯
- **S2-12 投资物业计量是港股版的关键差异点**：HKFRS 下地产公司普遍采用公允价值模式，重估损益**直进利润表且非现金**——报表利润可能一半是估值师「估」出来的。命中后必须剔除重估损益（盈亏双向）重估经营性盈利与 ROE：上行期剔收益、下行期剔亏损，禁止不对称处理
- 商誉：港股并购同样高发；红筹与内房通过合营/联营藏表外负债是港股特色，联动 S5-06——**合联营暴露已量化（H2-03）**：应占合联营业绩 ÷ 除税前溢利 >30%〔经验值〕或（应收合联营款 + 担保）÷ 归母净资产 >50%〔经验值〕→ 红灯；应收合联营/关连方款项并入 S2-10 杂项资产单列检查
- **明股实债看 NCI 裂口（S3-06）**：NCI 损益占比远大于 NCI 权益占比 = 资方以股权名义收固定回报，内房高发
- **每股维度（H2-04）**：净利增速与 EPS 增速的裂口是港股识假关键——供股/配售高发市场里总量增长 ≠ 股东回报；回购注销驱动裂口为负则是正向证据（2024 库存股新规后须核对注销口径）
- **H2-01 股本稀释是港股版的核心补丁**：供股/配售是港股摊薄的主机制（远大于美股的 SBC），已发行股数年增 >10% 或 5 年 ≥2 次供股即预警；与 H0-01 互证

## 第 3 层 盈利质量（赚的是不是真钱）

- 毛利率/费用率护城河逻辑不变；〔经验值〕阈值源自 A 股，港股一律同行对比优先
- S3-03 研发资本化率恢复适用（HKFRS 允许开发支出资本化，同 CAS）
- S3-04 主业成色（HK 口径）分子必须含**投资物业公允价值损益**——这是港股地产利润注水的主通道；**两阶段裁决**：剔除后主业强 + 占比高 = 预警（平台型公司投资收益属盈余配置，如腾讯处置收益大年，不误伤）；主业弱 + 占比高 = 红灯
- **S3-09 毛利率稳定性是识好第一代理**：5 年变异系数低于同行 + 成本上行期毛利率保持 = 定价权证据；大起大落 = 周期股而非护城河
- H3-01 Non-IFRS 差异率：腾讯等公司披露 Non-IFRS 利润，逻辑同美股 Non-GAAP；未披露的公司记「无法计算」而非放行
- S3-07 OCI 背离：跨国经营公司外币折算差额是结构性来源，须注明而非误判

## 第 4 层 现金验证（利润有没有人买单）

- 港股现金流量表普遍间接法，S4-01' 推导式（自利润表）：**估算收现 = 收益 − Δ应收类 + Δ合约负债**，长期 <1 → 红灯；⚠️ 禁止从经营现金流出发推导收现（CFO 已扣付现成本，高毛利公司会系统性失真误杀）
- **S4-02 口径警示**：NCI 损益占比高的公司（明股实债嫌疑），CFO ÷ 归母净利会系统性虚高——合并 CFO 含少数股东现金流，须以 CFO ÷ 年度溢利复核并双口径并列
- **地产公司 S4-02 比较前必须先剔除投资物业重估损益（盈亏双向）**——否则「利润含金量」会被非现金重估损益系统性扭曲而误判（上行期虚低、下行期虚高）
- 现金流肖像 8 类与多期判定五条规则同内核（逐年分类 → 主导型 → 最新年校验 → 红灯分级 → 事件扰动不剔除）；**18A/未盈利企业豁免肖像裁决，改现金跑道**（现金 ÷ 年烧钱 ≥2–3 年），避免与「评级上限可关注」死锁
- S4-07 股东回报检验：持续高分红或大额回购注销（须核对注销口径，仅回购不注销不计入）是利润真实性最强佐证；**累计分红超累计自由现金流 = 借钱分红**（恒大画像核心特征）；**「融资多回报少」与老千股闸口互证**——反复供股却从不回报股东的公司，提款机特征坐实
- 恒大式暴雷画像复盘：高杠杆（含永续债还原后）+ 债务到期墙与美元债错配 + 表外合联营负债 + 分红超自由现金流——多层同时报警

## 第 5 层 管理层与治理（人靠不靠谱）

- H5-01 大股东行为（港股口径）：质押、折价配售、减持三合一检查；披露权益（DI）是法定追踪渠道
- 做空报告是港股的「民间审计」（浑水对辉山乳业、香橼对恒大均为经典命中）：**因果顺序固定——财报否决级异常独立成立为前提，做空报告为增强证据 → 直接排除**；财报无独立异常时做空仅触发强制下钻（浑水对安踏多次做空未果为反例）——既不与市场 veto 信号对抗，也不替做空机构站台
- 关连交易：红筹/地产公司的持续关连交易须对照联交所批复上限逐笔检查
- 高危清单：仙股/细价股、壳股、18A 未盈利生物科技、内房股（高杠杆 + 表外负债）

## 第 6 层 综合判定（好生意长什么样）

- **ROE 与 ROIC 双核心并列**：识好看 ROIC（剔杠杆后的真实资本回报），排雷看 ROE；**H6-01 ROE 失真检查是双向的**：① 回购压净资产（美股向，港股较少）；② **重估储备虚增净资产**（港股向，HKFRS 特有）；③ 永续债入权益虚增分母——命中改判 ROIC（固定口径：NOPAT 盈亏双向剔除重估损益、投入资本含还原永续债、净现金公司剔超额现金）
- 杜邦三模式优先级不变：高毛利 > 高周转 > 高杠杆
- **好生意的完整财务画像**：高且稳定的 ROIC（≥12%〔经验值〕或同行前 1/3）+ 高效再投资（S6-06 增量资本回报持续高位）+ 毛利率稳定（S3-09 低变异系数）+ 每股维度真实增长（H2-04 裂口 ≤0）+ 主业成色足（S3-04 两阶段通过）
- 自洽性总检不变：营收/利润/现金流/应收/存货/周转率六者互证，任一独走必须有解释

## A+H 对照实验（港股版特有验证机制）

同一实体在 A 股（CAS 口径）与港股（HKFRS 口径）双重披露，是验证方法论跨市场一致性的天然实验：
1. 同一公司两套口径的归母净利润 / 净资产 / 经营现金流应基本一致，差异 >5% 必须能解释（准则差异/口径调整）
2. 七层框架在两侧应得出**同向结论**；若一侧红灯一侧放行，须复盘是准则差异还是框架缺陷
3. 对照实验标的建议：比亚迪（1211.HK / 002594.SZ）、招商银行（3968.HK / 600036.SH，注意银行走金融专用框架，仅作口径一致性验证）
