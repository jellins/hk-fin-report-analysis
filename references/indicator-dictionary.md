# 指标字典（Indicator Dictionary）— HKFRS 版 v1.1

> 本文件是港股财报诊断的**唯一指标来源**。执行诊断时只允许使用本字典中的指标、公式与裁决规则，禁止自创指标、禁止修改公式、禁止脱离口径计算。
> 指标 ID 与 A 股版（a-share-fin-report-analysis）、美股版（us-fin-report-analysis）保持同构，便于跨市场对比；港股特有指标以 `H` 前缀编号。
> HKFRS 与 IFRS 实质趋同，且 CAS 亦趋同 IFRS，故本版结构最接近 A 股版；凡与 A 股版口径不同之处均显式注明。
> v1.1 新增（2026-10 专家评审修订）：H1-02 永续债还原、H2-03 合联营暴露、H2-04 每股裂口、S3-09 毛利率稳定性、S6-06 增量资本回报；REIT 豁免行；18A 现金跑道裁决；S6-03 降风险级。新增 ID 一律追加尾部号段，不复用历史跳号。
> v1.1 数据源配套追加（2026-10-19 内置数据源落地）：字段表新增 A38 库存股、B26 每股基本盈利、B27 每股摊薄盈利（H2-01/H2-04 取数依赖，尾部号段追加，指标集不变）。
> 标注〔经验值〕的阈值为初筛代理指标，最终裁决必须落到「自身连续 ≥5 个财年趋势 + 同行业 2–3 家对比」。

## 通用口径（适用于全部指标）

- 报表口径：合并报表（consolidated financial statements），禁止使用公司单体数据
- 利润口径：本公司拥有人应占溢利（profit attributable to owners of the Company，归母口径），剔除非控股权益（NCI）
- 准则口径：HKFRS（香港财务报告准则）；在港上市内地企业按 CAS 或 IFRS 编制者，回执须注明准则口径
- 财年对齐：港股财政年度截止日多样（3/31、6/30、12/31 均常见），跨公司对比时必须在报告中注明各公司财年截止月份
- 记账本位币：港股公司记账本位币可为 HKD / RMB / USD（如腾讯为 RMB、汇丰为 USD），**必须在数据回执中注明币种**，跨币种对比先统一折算
- 披露载体：年度业绩公告 + 年报为主；中期报告（半年报）普遍未经审计，仅作参考、不作定性依据
- 平均值定义：（期初 + 期末）÷ 2
- 无科目处置：公司无该科目（如无永久资本证券、无合联营、无库存股）时回执填 0 并注明「无此科目」——不构成 MISSING，不得以 MISSING 绕过 A37/B24 等结构性检查字段

### MISSING 分层处置（数据缺失时的固定规则）

- 字段级：取不到的字段在回执中标注 `MISSING`，禁止估算、禁止编造
- 指标级：某指标所需字段 MISSING → 该指标状态记为「无法计算」，不参与红灯/预警/加分任何计数
- 评级级：▲核心字段缺失导致任一否决级指标无法计算 → 输出「数据不足，暂不定级」；非否决级指标「无法计算」≥3 个 → 触发降档（仅适用于正向评级，见评级聚合规则）；无法计算指标清单必须列入诊断报告
- 附注补齐义务：非否决级指标「无法计算」≥3 个时，定级前必须先从年报附注/业绩公告原文（披露易）人工摘录补齐（结构化数据源未覆盖字段）；确认原文亦无披露后才可按降档规则处理

## 第 0 层 前置闸口（任一不过则终止）

> 执行顺序：**G0-05 行业适用性与 G0-06 风险警示优先于 G0-01～G0-04 执行**；全部港股标的另须先过 H0-01 老千股结构闸口。

| ID | 检查项 | 通过条件 | 所需数据 |
|---|---|---|---|
| G0-05 | 行业适用性（优先执行） | 非银行/保险/券商/多元金融行业；金融业 → 终止诊断并输出标准说明：「金融企业报表结构与指标体系完全不同（资本充足率/不良率/拨备覆盖率等），本框架强行套用会产生系统性误判，建议使用金融专用分析框架」 | 行业分类（数据源可得口径，回执标注） |
| G0-06 | 风险警示状态 | 当前未处于清盘呈请（winding-up petition）未解除、长期停牌（主板连续 ≥18 个月 / GEM 连续 ≥12 个月触发除牌程序）、已进入除牌程序状态；命中 → 直接排除 | 公司最新状态（行情/公告/联交所披露易） |
| G0-01 | 审计意见 | 近 5 个财年全部为无保留意见（unqualified opinion），更早年度不追溯；带强调事项段的无保留意见 → 通过但记预警，须阅读强调事项内容并写入报告；**含持续经营（going concern）重大不确定性段落的 → 升级风险级红灯并强制下钻**（暴雷前兆，严重性区别于一般强调事项） | 各年度核数师报告（年报，D01） |
| G0-02 | 报表口径 | consolidated + 归母口径 | 数据源元信息 |
| G0-03 | 上市年限 | 上市满 3–5 年，否则降权并明示；**借壳（港股称「反向收购」RTO）按反收购完成日起重新起算**；无法核验借壳史时标注「未核验借壳史」 | 上市/RTO 完成日期（D09） |
| G0-04 | 数据完备性 | 本公司连续 ≥5 财年三表齐备为硬条件（不齐则终止）；仅同行对照组不齐 → 进入「无同行对比降级模式」（裁决改用 5 财年趋势 + 绝对参照线，评级上限「可关注」，见评级聚合规则） | 数据需求清单覆盖检查 |
| H0-01 | 老千股结构闸口（港股特有，复合检查） | 以下五项逐一检查：① 供股/合股频率：近 5 年供股（rights issue）或合股（share consolidation）≥2 次；② 长期低价：连续 12 个月月均收盘价低于 HK$1（仙股/细价股）且无盈利与净资产支撑（归母净利为负或每股净资产 <HK$0.5）；③ 频繁更名换主业：近 5 年更名 ≥2 次且伴随主业切换；④ 股权高度集中：控股股东及一致行动人持股 >70% 且公众持股 ≤28%（贴近 25% 法定下限的缓冲带）；⑤ 向下炒特征：反复以 >15% 折价配售新股，或供股折价 >25%（供股折价通常深于配售）。**命中 ≥2 项 → 直接排除**；命中 1 项 → 记预警并列入报告 | 历年股本变动/配售/供股/合股公告（D14）、股价历史、股东结构（D10） |
| H0-02 | 上市机制标记 | 识别并标记：WVR（不同投票权架构，股名后缀 -W）、18A 未盈利生物科技（后缀 -B）、第二上市（后缀 -S）、SPAC、介绍上市、GEM 创业板。**不否决**，但改变后续裁决口径：18A/未盈利 → 适用未盈利企业豁免（评级上限「可关注」）；WVR → 第 5 层治理指标从严执行；GEM → 全清单从严 | 招股书/年报上市机制披露 |

## 第 1 层 安全性

| ID | 指标 | 公式 | 参照线 | 裁决规则 | 红灯分级 |
|---|---|---|---|---|---|
| S1-01 | 现金覆盖有息负债 | （现金及现金等价物 + 短期投资 + 定期存款〔含中长期定期存款，可提前支取属性〕）÷ 有息负债* | ≥1 | 连续多年 <1 → 红灯（债务生死线失守）；单年 <1 → 预警；若利息收入 ≥ 融资成本（净现金结构）且覆盖比趋势改善 → 红灯降为预警并在报告注明 | 风险级 |
| S1-02 | 有息负债率 | 有息负债 ÷ 总资产（有息负债含还原后的永久资本证券，见 H1-02） | >60%〔经验值〕高危 | 超线 → 原则上回避；地产/公用事业按豁免表处理 | 风险级 |
| S1-03 | 存贷双高 | 现金充裕却大量举债，且利息收入 ÷ 平均现金显著低于市场利率 | 利息收入匹配 | 双高 + 利息收入异常偏低 → 红灯（现金真实性存疑；港股老千股语境下从严，可直接排除）；结构性差异（境内外币种错配）须在报告中注明 | 否决级 |
| S1-04 | 流动比率 / 速动比率 | 流动资产 ÷ 流动负债；速动剔除存货 | 参照约 2 / 约 1 | 仅辅助预警：持续恶化或显著低于同行 → 预警 | — |
| S1-05 | 利息保障倍数 | （除税前溢利 + 利息费用）÷（费用化利息 + 资本化利息合计，C11） | 越高越好 | 逼近 1 或持续下滑 → 预警；⚠️ 分母必须含资本化利息——内房将利息大量资本化进发展中物业，仅看利润表融资成本会系统性高估保障倍数 | — |
| H1-01 | 债务到期墙 | 未来 2 年到期债务 ÷（现金 + 年经营现金流）；浮动利率占比；**外币债务占比（美元债 vs 人民币收入错配）** | 到期集中 + 高浮动占比 + 高外币占比 | 紧缩周期命中 → 预警升级；内房股等高杠杆行业必查（「到期墙 + 境外美元债 + 本币贬值」为内房暴雷标准组合） | — |
| H1-02 | 永续债还原检查（港股强化） | 权益内永久资本证券识别（A37/D21）；还原调整：有息负债 += 永续债本金，利息费用 += 永续债分派（票息） | 永续债 ÷ 归母净资产 >20%〔经验值〕；票息跳升重置日临近 | 内房/基建/综合企业必查：识别后强制按还原口径重算 S1-01/S1-02/S1-05/H1-01 与 ROE 并注明；占比超线或重置临近 → 预警；通过 NCI/夹层结构隐性嵌入的 → 红灯升级（联动 S5-06/S3-06） | — |

*有息负债 = 短期借贷 + 一年内到期的长期借贷 + 长期借贷 + 债券/票据 + 租赁负债（finance lease liabilities）。⚠️「票据」仅指债券性质的应付票据（notes payable）；CAS 披露公司（H 股）报表中的「应付票据」为贸易结算票据（银行/商业承兑），**不属于有息负债**，禁止并入（T3 回归实测：误并把 CATL 有息负债率从 12.3% 抬到 20.2%）

## 第 3 层 盈利质量

| ID | 指标 | 公式 | 参照线 | 裁决规则 | 红灯分级 |
|---|---|---|---|---|---|
| S3-01 | 毛利率 | （收益 − 销售成本）÷ 收益 | 稳定 >40%〔经验值〕多有护城河；<20% 红海 | 同行对比优先；无支撑显著高于同行 → 红灯（造假嫌疑） | 否决级 |
| S3-02 | 运营费用率 | （销售及分销费用 + 行政费用 + 费用化研发开支）÷ 毛利 | <30% 优秀；30–70% 正常；>70%〔经验值〕排除 | 单年超线 → 预警 + 下钻（禁止单年定性）；连续多年超线 → 红灯；⚠️ 分子不含融资成本——利息负担由 S1-05 独立裁决，避免重复计罚 | 否决级（须连续多年命中） |

**S4-06 多期判定规则（替代单年定性，与总则「禁止单年数据定性」对齐）**

1. **逐年分类**：连续 5 个财年各自按符号八分类，序列全量呈现于报告
2. **主导型**：5 年中出现频次最高的类型为定性标签；并列取较差者，优劣序固定：奶牛 > 老母鸡 > 蛮牛 > 妖精 > 排除类四型
3. **最新年校验**：最新年优于主导型 → 标「边际改善」；劣于主导型 → 标「边际恶化」并触发当年大额现金事件下钻
4. **红灯分级**：主导型为排除类 → 否决级红灯；主导型非排除类但 5 年内 ≥2 年落入排除类 → 风险级红灯；仅最新 1 年为排除类且此前健康 → 预警 + 下钻当年事件，不定红灯
5. **事件扰动**：某年符号由一次性事件（供股/大额配售/并购/出售资产）造成时，报告注明「事件驱动型波动」作裁决参考，但**不从序列中剔除**——剔除权不交 Agent

## 评级聚合规则（Rating Aggregation，四档评级的唯一裁决依据）

> 本章节是四档质地评级的**唯一裁决规则**。Agent 只允许按本章节机械裁决，禁止自由裁量聚合。
> 计数闭合校验：否决级 12 项 + 风险级 18 项 + 无红灯 28 项 = 58 项指标。

### 1. 四档门槛

| 评级 | 机械裁决条件 |
|---|---|
| 直接排除 | ① G0 任一闸口不过（含 H0-01 命中 ≥2 项）；或 ② 任一否决级红灯（经 D 组下钻后嫌疑仍未排除） |
| 高风险回避 | 风险级红灯 ≥1；或预警 ≥3（S5-07 高危行业 ≥2） |
| 优质候选 | 无任何红灯 + 预警 ≤1（高危行业为 0）+ 三硬条件同时满足（S6-01 ROE 连续多年 ≥15%〔经验值〕或同行业前 1/3 分位且趋势稳定/上行；H6-01 命中时以 ROIC ≥12%〔经验值〕或同业前 1/3 分位替代；S4-06 主导型为奶牛/老母鸡；S4-02 利润含金量长期累计 ≥1）+ 加分项 ≥1（S2-14 / S2-15 / S4-07） |
| 可关注 | 不满足以上三档的其余情形 |

### 2. 裁决顺序总则

按固定顺序机械裁决：① 按四档门槛初步定档 → ② 应用降档规则（非否决级指标「无法计算」≥3 个且初步定档为正向评级〔优质候选/可关注〕→ 降一档；负向评级不降档，改标「暂定」）→ ③ 应用评级上限裁剪（未盈利企业/18A / 无同行对比降级模式，上限「可关注」；多个上限同时触发取最严）→ ④ 附加评级状态标注（暂定 / 数据不足）。

### 3. 预警计数口径

「预警」全集 = 全部指标级预警 + 全部闸口级预警（含 G0-01 强调事项段预警、H0-01 命中 1 项、S4-06 边际恶化及单年排除类预警），逐条列入评级依据摘要。计数前依次应用两条确定性修正：

- **根因合并**：多个指标预警经下钻确认源于同一根因事件（如同一笔一次性资产处置、同一减值周期）→ 合并计为 1 个预警；评级依据摘要须注明根因事件与涉及的全部指标 ID。
- **已解决预警退出**：预警事项经下钻确认已完全解释、且对应指标在最近 2 个财年已恢复正常（不再触发预警条件）→ 移出预警计数，转入报告「历史已解决事项」节列示。

### 4. 保护规则

- 下钻后仍「待验证」的嫌疑项 ≥1 → 评级标注「暂定」，数据补齐后复核
- ▲核心字段缺失导致任一否决级指标无法计算 → 输出「数据不足，暂不定级」，不强行给档（行业豁免表已豁免的指标除外）
- 「暂定」「数据不足」等评级状态统一为状态标注，可多值并列（如「高风险回避（暂定）」）

### 5. 评级依据摘要（报告必含）

固定字段：红灯清单（指标 ID + 分级）｜预警清单（指标 ID + 原因）｜三硬条件命中情况｜加分项命中情况｜降档与上限适用记录｜状态标注。
