# 港股财报术语表（Glossary）

> 诊断报告中出现的每个英文术语/港股专有名词，须按本表配中文翻译与一句话解释。目标：读者一眼看懂这是什么、为什么关键。

## 核心方法论指标（报告高频）

| 术语 | 中文 | 一句话解释 |
|---|---|---|
| HKFRS | 香港财务报告准则 | 港股法定记账口径，与 IFRS（国际准则）实质趋同 |
| IFRS | 国际财务报告准则 | 全球通用准则体系，HKFRS 的母版 |
| Non-IFRS | 非国际准则（管理层调整口径） | 公司剔除"不喜欢"的成本后的美化版成绩（腾讯等披露）——必须与 IFRS 数字并排看 |
| CFO（Operating Cash Flow） | 经营活动现金流净额 | 主业一年真实收进来的现金，利润真伪的终极验证器 |
| Capex（Capital Expenditure） | 资本开支 | 买物业厂房设备等长期资产花的钱，扩张的代价 |
| FCF（Free Cash Flow） | 自由现金流 | CFO 减去 Capex 后真正可自由支配的钱，派息的真正来源 |
| ROE | 净资产收益率 | 股东每投 1 元一年赚回多少，综合盈利能力核心指标 |
| ROIC | 投入资本回报率 | 股权+债权全部投入资本的回报率，ROE 被重估/回购扭曲时的替代标尺 |
| Gross Margin | 毛利率 | 卖 1 元货扣掉直接成本剩多少，生意先天禀赋的第一标志 |
| Operating Profit | 经营溢利 | 主业经营赚到的钱（港股披露口径因公司而异） |
| Profit attributable to owners of the Company | 本公司拥有人应占溢利（归母净利润） | 剔除少数股东后真正属于上市公司股东的利润 |
| EPS / Diluted EPS | 每股盈利 / 摊薄后每股盈利 | 每股赚多少；摊薄口径把购股权行权后的稀释算进去，更保守真实 |
| Dividend / Payout Ratio | 股息 / 派息率 | 港股股东回报的主渠道；派息率 = 分红 ÷ 归母净利润 |
| Cash Runway | 现金跑道 | 现金及短期投资 ÷ 年烧钱速度（经营净流出 + 资本开支），未盈利企业（18A）的生存线指标，替代现金流肖像裁决 |
| Incremental ROIC | 增量资本回报率 | 新增利润 ÷ 新增投入资本，验证留存利润再投资是否仍是好生意（资本配置能力） |

## 报表结构类（HKFRS 惯用表述）

| 术语 | 中文 | 一句话解释 |
|---|---|---|
| Revenue | 收益 | 港股利润表第一行，即营业收入 |
| Cost of Sales | 销售成本 | 即营业成本 |
| Trade Receivables | 贸易应收款项 | 客户打的白条，增速持续超收益增速是红色警报 |
| Trade Payables | 贸易应付款项 | 欠供应商的钱，高且稳定 = 无偿占用上游的产业链强势证据 |
| Contract Liabilities | 合约负债 | 客户先打钱、货还没交——地产公司即预售楼款，先款后货是正向证据 |
| Contract Assets | 合约资产 | 活干了钱还没收，与应收合并从严看待 |
| Investment Properties | 投资物业 | 收租/增值持有的物业；HKFRS 允许公允价值模式，**重估收益直进利润表且非现金**——港股地产利润注水主通道 |
| Revaluation Reserve | 重估储备 | 资产重估增值进权益的"蓄水池"，HKFRS 特有，会虚增净资产压低 ROE |
| Goodwill | 商誉 | 收购时多付的溢价，无实物、不能变现，减值时直接吞噬利润 |
| Inventories | 存货 | 仓库里的货（地产公司含发展中物业）；周转降+毛利率升是经典造假信号 |
| NCI（Non-controlling Interests） | 非控股权益 | 并表子公司里不属于上市公司股东的那部分，利润可能被它分走 |
| OCI（Other Comprehensive Income） | 其他全面收益 | 绕过利润表的盈亏暗流（外币折算、重估等），净利之外必须看一眼 |
| Finance Costs | 融资成本 | 港股口径的利息费用行 |
| Loss Allowance | 亏损拨备 | 应收坏账准备，计提宽松度须与同行对比 |
| Maturity Profile | 债务到期结构 | 未来各年到期债务分布，到期集中 + 高浮动占比是紧缩周期生死线 |
| Perpetual Securities / Perps | 永久资本证券（永续债） | 计入权益的「债」：票息走权益分配不进利润表，同时美化负债率与利润——内房/基建必查还原（H1-02） |
| Share of Results of JVs & Associates | 应占合营及联营企业业绩 | 表外项目公司按份额回表的利润行，内房表外藏债与利润注水的交汇点 |
| 明股实债 | 明股实债 | 资方以少数股东（NCI）身份进项目公司、实为放贷收固定回报——NCI 损益占比远大于 NCI 权益占比是识别裂口 |
| FFO（Funds from Operations） | 营运现金流（REIT 口径） | 归母净利 + 折旧摊销 − 投资物业重估损益，REIT 利润含金量的正确分子口径 |
| Capitalized Interest | 资本化利息 | 计入发展中物业/在建工程成本而非利润表的利息——内房利息负担的冰山在水下，利息保障倍数分母必须含它 |

## 港股市场制度类（港股版的"雷区地图"）

| 术语 | 中文 | 一句话解释 |
|---|---|---|
| 供股（Rights Issue） | 供股 | 按持股比例向股东折价发新股，不供就被摊薄——老千股收割小股东的第一工具 |
| 合股（Share Consolidation） | 合股 | 多股合并为 1 股（如 10 合 1），把仙股价格做高以便下一轮供股向下炒 |
| 配售（Placing） | 配售 | 向特定对象发新股，反复大折价配售 = 向下炒信号 |
| 拆股（Share Subdivision） | 拆股 | 1 股拆多股，与合股相反 |
| 仙股 / 细价股（Penny Stock） | 仙股 | 价格长期低于 HK$1 的股票，老千股高发区 |
| 老千股 | 老千股 | 通过"供股摊薄 → 向下炒 → 合股 → 再供股"循环收割小股东的股票；**报表可能正常，杀机在股本游戏里** |
| 向下炒 | 向下炒 | 庄家配合大折价配售持续压价出货的操纵手法 |
| H 股 | H 股 | 内地注册、港股上市的内地企业（如比亚迪 1211.HK） |
| 红筹（Red Chip） | 红筹股 | 境外注册、内地资产的港股公司，关联交易是特色风险点 |
| A+H | A+H 两地上市 | 同一实体 A 股 + 港股双重上市，跨市场口径一致性验证的天然实验 |
| WVR（Weighted Voting Rights） | 不同投票权架构（同股不同权） | 股名后缀 -W（如小米-W）；创始人 1 股多票，小股东保护弱化，治理层从严 |
| 18A | 未盈利生物科技上市章节 | 股名后缀 -B；未盈利企业，盈利质量层失效、评级上限「可关注」 |
| 第二上市（Secondary Listing） | 第二上市 | 股名后缀 -S（如阿里-SW），主上市地在海外 |
| GEM | 创业板 | 港股创业板，门槛低风险高，全清单从严 |
| RTO（Reverse Takeover） | 反向收购（借壳） | 港股借壳叫法；借壳后财务历史自完成日起重新起算 |
| REIT | 房地产投资信托基金 | 强制分派 ≥90% 可分派收入的收租载体（领展为代表）；财务口径特殊（FFO/分派率），走行业豁免表 |
| Treasury Shares | 库存股 | 2024 年 6 月联交所新规后回购可不注销、持作库存股；计算股本稀释与 EPS 必须核对注销口径 |
| Going Concern | 持续经营假设 | 核数师对「公司还能不能活」的保留——带此段落的无保留意见是暴雷前兆，红灯处理 |
| 清盘呈请（Winding-up Petition） | 清盘呈请 | 债权人申请公司破产清算的法律程序，未解除 → 直接排除 |
| 停牌 / 除牌 | 停牌 / 除牌 | 主板停牌连续 ≥18 个月 / GEM 连续 ≥12 个月触发除牌程序（上市规则 6.01A / GEM 9.14A） |
| 披露易（HKEXnews） | 联交所披露易 | 港股法定公告平台，年报/供股/核数师辞任等原文都在这里 |
| 权益披露（DI, Disclosure of Interests） | 权益披露 | 大股东/董事持股变动的法定申报，内部人用不用脚投票看这里 |
| 核数师 | 核数师 | 港股对审计师的叫法；核数师"辞任"伴随分歧说明，比到期"轮换"危险 |
| 关连交易（Connected Transactions） | 关连交易 | 港股口径的关联交易，须对照联交所批复上限逐笔检查 |
| 港股通（Southbound Connect） | 港股通（北水） | 内地资金买港股的通道，北水持仓变化可作资金面参考 |
| Short Seller Report | 做空报告 | 市场"民间审计"（浑水、香橼等），港股是做空高发市场——命中且与财报异常互证时直接排除 |
